# AURA — обновления из GitHub Releases

Текущий статус: **реализована первая интеграция в исходники и UI; end-to-end обновление пока не проверено** из-за отсутствия двух стабильных APK с одной подписью.

## Сценарий

- Пользователь открывает иконку AURA → экран активации `SetupActivity`.
- Приложение один раз проверяет `https://api.github.com/repos/crakacr-alt/AuraGlass/releases/latest` по HTTPS.
- Только **stable** (не `prerelease` и не draft), только SemVer новее установленного.
- При наличии нового релиза — панель и кнопка скачать APK. По выбору — уведомление в шторке *после такого же входа*, а не в фоне.
- Нажатие скачивания → Android DownloadManager, APK в приватном каталоге AURA.
- Нажатие установки → локально сверить SHA-256 (поле `assets[].digest`), размер, appId, код версии и подпись с уже установленным приложением.
- Дальше **только штатный системный установщик Android**, при отсутствии разрешения на этот источник Android открывает системные настройки.
- Нет серверного push, фоновых задач, автозапуска после загрузки или `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`.

## Необычные случаи

- `404` на `releases/latest` означает, что **стабильный релиз пока отсутствует**.
- Если GitHub не предоставил SHA-256 asset digest, APK не предлагается к автоматической установке; пользователю можно открыть страницу Releases.
- Если новая подпись отличается от текущего debug APK — запрещаем обновление; файл нельзя безопасно ставить «поверх».
- Android 13+ разрешение `POST_NOTIFICATIONS` спрашивается только при включении тумблера уведомлений.
- APK не загружается, пока пользователь не нажал кнопку.
- Android может ограничивать установку APK из неофициальных источников; не обходить эти ограничения.

## Необходимые проверки перед приёмкой

- [ ] Никакого запроса к GitHub в фоне/при перезагрузке/каждом входе в HomeActivity
- [ ] Нет стабильного релиза → не показывать ложное обновление
- [ ] Стабильный v1.0.1 поверх v1.0.0 → скачать, проверить, подтвердить, сохранить данные
- [ ] Prerelease v1.1.0-rc → проигнорировать
- [ ] Невалидный URL / asset без SHA256 / битый APK / другой appId / другой сертификат → блокировать
- [ ] Неизвестные источники запрещены → только системная инструкция и повторная кнопка
- [ ] Нет разрешения уведомлений → карточка в приложении работает и не спамит в шторку
- [ ] Прерывание сети/закрытие приложения/повторная загрузка → нет падений, корректное сообщение
- [ ] Samsung S24 Ultra и Android 8/10/13/15/16 → без потери домашнего экрана
