# AURA Island — системный мини-центр событий

## Внешний вид

Основа — стеклянная капсула из AURA GLASS, **не копия iPhone**. Под фронтальной камерой S24 Ultra: компактный тёмный/светлый адаптивный контур, мягкий блик, глубина, согласованные отступы с One UI и живыми обоями. Островок может быть выключен независимо от лаунчера, обоев и погодного виджета.

По событиям капсула расширяется пружинной анимацией без резких скачков высоты. Во время дождя — микрокапли у краёв, во время льда — лёгкий холодный ободок, вечером — тёплые отражения. Эффекты никогда не мешают чтению, не имитируют настоящий системный вырез и не закрывают камеру.

### Состояния

1. **Свернутый:** медиа / состояние зарядки / одно важное уведомление / часы или без содержимого.
2. **Уведомление:** иконка приложения, текст только если разрешён, действия «открыть», «ответить» (если системное `RemoteInput` присутствует), «скрыть».
3. **Несколько событий:** стек 2–3 карточек с вкладками или вертикальным раскрытием; сортировка по важности.
4. **Медиа:** управление через Android `MediaSession`, прогресс трека и устройство вывода.
5. **Быстрые действия:** таймер, батарея, Bluetooth, погода, открытие редактора и звуковой панели.
6. **Громкость:** пять вертикальных адаптивных слайдеров, как на присланном скриншоте, с настраиваемыми оттенками AURA, светящимися заполнениями и значками.
7. **Отдельный звук приложений:** интеграция с Samsung SoundAssistant/Good Lock, когда он установлен. Стандартный Android API не предоставляет лаунчеру универсального изменения уровня каждого чужого приложения.

### Жесты

- Тап: раскрыть / открыть текущее событие после явного выбора.
- Свайп вниз: показать события и управление.
- Свайп вверх: свернуть.
- Свайп влево/вправо: переключение карточек или закрытие только собственного интерфейса, не удаление системного уведомления без отдельного действия.
- Долгое нажатие: список разрешённых приложений, внешний вид, разрешения и конфиденциальность.

### Уведомления и разрешения

Android `NotificationListenerService` требует, чтобы пользователь **сам включил доступ к уведомлениям** в настройках системы; приложение не может включить его скрытно. Уведомления отражаются локально без отправки на сервер. Текст сообщений по умолчанию скрыт. Исключать секретные/конфиденциальные уведомления, защищённые экраны и не отображать содержимое на lock screen. На некоторых устройствах и в рабочих профилях доступ недоступен.

`PendingIntent` и `RemoteInput` нужно использовать безопасно и только с объектами из системного уведомления, никогда не подделывать внешние действия.

### Экран поверх чужих приложений

Внутри AURA Home островок работает без спецразрешений. Для отображения **над другими приложениями** нужно отдельное пользовательское разрешение `SYSTEM_ALERT_WINDOW`, а Android может ограничить касания, отображение на защищённых экранах и фоновую активность. В первоначальном релизе эта функция может быть отключена, пока не пройдёт проверки Samsung/Android.

### Контроль громкости

`AudioManager.setStreamVolume` позволяет менять **системные аудиопотоки**; отдельные приложения таким способом не регулируются. На Samsung каналы «звонок» и «уведомления» могут быть связаны, а режим DND накладывает дополнительные ограничения. На устройствах без поддержки отдельных каналов интерфейс показывает фактический статус, а не неработающий ползунок.

Глубокое управление громкостью отдельных приложений возможно только при наличии подходящей интеграции производителя, например Samsung SoundAssistant; открываем её настройки, не заявляя выдуманной поддержки API.

### Приоритет и приёмка

P0 для стабильного релиза: островок на рабочем столе, безопасные уведомления по opt-in, реальный микшер системных потоков, управление основным медиа, адаптивные жесты. Межприложный overlay, расширенные действия уведомлений и индивидуальные уровни сторонних приложений — только при подтверждённой возможности на Samsung.

Тесты: S24 Ultra/One UI, входящие сообщения/банковские уведомления/OTP, звонки, тихие уведомления, DND, BT-гарнитура, подключение/отключение наушников, 60/120 Гц, AOD/экран блокировки, полноэкранные игры, отсутствие сети, обновление приложения.

## Реализованное в development-ветке

- Реальные музыкальные события MediaSession: название, автор, приложение-источник, обложка, пауза/воспроизведение, следующий/предыдущий, seekTo только при ACTION_SEEK_TO
- Адаптивная капсула внутри рабочего стола, жесты раскрытия и локального скрытия события
- Опциональная реальная FFT-звуковая волна; если на устройстве захват запрещён, анимация не подделывает басы
- Телефонные уведомления категории CALL с приватностью по умолчанию; микрофон и завершение — только когда Samsung Phone или другое приложение предоставило конкретное действие уведомления
- Отдельный 5-канальный системный микшер, опциональный переход к Samsung SoundAssistant
- Обычные уведомления и их открытие через предоставленный PendingIntent, без отправки содержимого на сервер
- Для APK из GitHub на Android 13+ уведомления могут подпадать под **Restricted Settings**. Приложение не пытается обходить защиту системы; пользователь принимает решение самостоятельно после проверки источника

Не реализовано пока: межприложный overlay, замена интерфейса звонков Samsung, полный журнал уведомлений и универсальный per-app mixer. Не включать эти возможности в рекламное описание стабильного релиза до реального теста.
