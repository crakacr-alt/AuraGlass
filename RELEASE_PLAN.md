# AURA GLASS — критерии полноценного релиза

**Единая матрица выхода на инженерные 100%:** [RELEASE_100_ROADMAP.md](RELEASE_100_ROADMAP.md). Для обновлений см. [GITHUB_UPDATES.md](GITHUB_UPDATES.md).

Статус: **готовится**, выпуск v1.0 запрещён до прохождения всех обязательных пунктов. Текущая альфа не является готовым приложением.

## P0. Установка, безопасность, обновление

- [ ] Единый приватный release-keystore хранится в GitHub Actions Secrets, не в репозитории; сертификат остаётся одним и тем же между версиями.
- [ ] Версии используют неизменный `applicationId = com.auraglass.app`, всегда увеличивающийся `versionCode`; `versionName` соответствует тегу релиза.
- [ ] CI проверяет APK Signature Scheme, package ID, минимальную версию Android, сертификат подписи и установку поверх предыдущего подписанного релиза.
- [ ] При первом переходе с debug-alpha пользователь получает предупреждение о возможной несовместимости подписи; настройки экспортируются до удаления.
- [ ] Стабильная версия публикуется **только вручную**, только после тестов и подписи; нет автоматических публикаций на каждый push.
- [ ] Проверка обновлений через официальный GitHub Releases API (только stable, не prerelease), с настройкой частоты и возможностью отключить. Скачивание и установку подтверждает пользователь.
- [ ] Проверка SHA-256 загружаемого APK и совпадения сертификата до передачи системному установщику; откат версии запрещён.
- [ ] Нет root, несанкционированного изменения системных параметров или автоматической смены обоев.

## P0. Полноценный лаунчер

- [ ] AURA появляется в выборе домашнего приложения на Samsung One UI и других поддерживаемых Android.
- [ ] Рабочий стол открывается и по нажатию Home, и после перезапуска смартфона.
- [ ] Редактируемые страницы; перетаскивание и удаление ярлыков; создание/редактирование папок.
- [ ] Dock, сетка, поиск, сортировка и скрытие приложений.
- [ ] Поддержка внешних виджетов Android через `AppWidgetHost`: выбор, привязка, настройка, изменение размера, обновление и удаление.
- [ ] Жесты и системная навигация не вызывают мерцаний, зависаний или блокировки пользователя.
- [ ] Настройки сохраняются; есть резервное копирование, восстановление и возврат к One UI Home.

## P0. Живые обои

- [ ] Реальный сервис WallpaperService с системным предпросмотром, выбором "Установить" / "Оставить системные".
- [ ] Анимация остаётся живой за иконками лаунчера; корректно останавливается на выключенном экране.
- [ ] Режимы: ясная погода, дождь, гроза, снег, лёд, роса, туман; день/вечер/ночь и переходы.
- [ ] Нет растяжений, видимых швов, мерцаний/скачков при изменении экрана или погодных условий.
- [ ] Энергосберегающий режим, снижение частоты кадров вне экрана, проверка тепловых ограничений.

## P0. Дизайн и анимации

- [ ] Цвета/контраст/размеры сверены с утверждёнными концептами для Galaxy S24 Ultra.
- [ ] Правдоподобные прозрачные панели с ограниченным, читаемым размытием и стеклянными бликами.
- [ ] Переходы: временной цикл, погодные режимы, нажатия на ярлыки, открытие папок, панели и редактор.
- [ ] Плавные 60 Гц на S24 Ultra в обычном режиме, адаптация под частоту экрана и Battery Saver.
- [ ] Учитываются Reduce Motion, AMOLED/тёмный режим, динамический цвет и контрастность.

## P0. ICE GLASS — ледяная тема и физически мотивированное стекло

- [ ] **Климатический иней:** использовать температуру и влажность из достоверного свежего прогноза, учитывать точку росы как ориентир и явно отличать художественную симуляцию от реальных измерений поверхности
- [ ] **Параллакс:** отключаемое смещение дальних звёзд и лент сияния по датчику гравитации, диапазон и чувствительность в настройках; датчик не активен при невидимости, Reduce Motion и экономии батареи
- [ ] **Снежная кромка:** отдельный накопительный слой на стеклянных карточках и погоде, локальное таяние пальцем, плавное восстановление, отсутствие блокировки кликов и текста
- [ ] **Кристальная оптика:** субпиксельные блики и прозрачные грани без белой засветки, сравнение с эталоном на фотографических кадрах
- [ ] **Тактильность:** единственный мягкий отклик на начало касания и возможность отключить его, уважение системного выключателя виброотклика
- [ ] **Тепловой режим:** автоматическое уменьшение количества частиц, слоёв сияния и FPS при Android thermal status и Power Save; в окнах без видимости ни рендеринга, ни активных датчиков
- [ ] Кнопка «Ледяная ночь» и полноценный предпросмотр: фон не должен зависать, обои применяются только через системный диалог
- [ ] **Независимые эффекты**: лёд, снег, северное сияние, яркие звёзды, галактическая пыль, кометы и метеоры, туман/роса; пользователь может отключить любой из них
- [ ] Модель поверхности: тепло пальца очищает иней по траектории, распространяется на соседние участки, остывает; влага постепенно конденсируется, после чего снова прорастают кристаллы
- [ ] Рисование одновременно в редакторе и полноэкранном предпросмотре; живые обои получают касания через WallpaperService только там, где оболочка Android передаёт их
- [ ] На лёгком стекле — тонкий конденсат, на ледяном — плотные дендритные ветви, границы кристаллов и холодные блики; без резкого восстановления целого рисунка одним кадром
- [ ] Размера «тёплого» следа достаточно для пальца, корректно работает непрерывный свайп, быстрые касания и переход через края; никакого растягивания по Y
- [ ] Независимая скорость снегопада и ветра, разные размеры снежинок и глубина; траектории без рывков при смене прогноза
- [ ] Aurora: многослойные ленты с медленным движением, плавным появлением на ночном небе; звёзды — разная яркость, мягкое мерцание; галактика — широкая размытая полоса; кометы — длинный затухающий хвост
- [ ] **Эффекты при касании стеклянных панелей/элементов интерфейса**: световая деформация, мягкое нажатие и возврат, связанные с общей темой; не путать с эффектами полотна обоев
- [ ] При переходе «утро → день → вечер → ночь» цвет, освещение, яркость неба, отражения и фазы не должны прыгать; auto-режим опирается на локацию/рассвет, когда данные есть
- [ ] Ограничение ресурсоёмкости: не более 2–3 мс CPU на шаг теплового слоя при нормальной нагрузке (требует измерения); при снижении кадров и Battery Saver — деградация качества без остановки интерфейса
- [ ] Проверка на 60/120 Гц, в лаунчере/на предпросмотре, на экране блокировки (где разрешено), при длительной работе, после поворота, смены темы и открытии приложений
- [ ] Не выдавать художественную галактику и кометы за реальную астрономическую обстановку или модель теплопередачи с измеряемой точностью

## P0. AURA Island — уведомления и управление звуком

- [ ] **Встроенный островок в AURA Home**: компактная капсула под фронтальной камерой, настраиваемая под безопасную область выреза Galaxy S24 Ultra; не перекрывает системные индикаторы
- [ ] Разворачивание по тапу/свайпу вниз, смахивание события в сторону, удержание для настроек; анимации появления, объединения и закрытия не дёргают интерфейс
- [ ] Уведомления разных приложений через `NotificationListenerService` **только после отдельного разрешения Android**: название приложения, иконка, заголовок, краткий текст (при разрешённом предпросмотре), группировка и счётчик
- [ ] Нажатие на уведомление открывает его родное приложение через `PendingIntent`, только если действие предоставлено системой; быстрый ответ — только при поддержке `RemoteInput`
- [ ] Приватность: по умолчанию скрывать текст, OTP и другие чувствительные сведения, отдельный список разрешённых приложений, режим «Не беспокоить», запрет отображения на экране блокировки и в защищённых приложениях
- [ ] Медиаплеер: название, обложка, прогресс и play/pause/next через системную MediaSession (только при законном доступе)
- [ ] Компактные события: таймер, секундомер, будильник, зарядка, аккумулятор Bluetooth, навигация, звонок (при наличии поддерживаемого системного события/интента)
- [ ] Пять реальных слайдеров системных каналов: медиа, вызов, уведомления, будильник, системные звуки через AudioManager; учитываем объединённые ползунки Samsung и ограничения DND
- [ ] **Громкость отдельных приложений**: только через поддерживаемые системные/Samsung-интеграции. Не показывать фиктивные ползунки, если Android не предоставляет управление
- [ ] Островок доступен для полного отключения. Никаких постоянных оверлеев без отдельного разрешения; межприложный режим — только после тестов OEM/Android overlay
- [ ] Проверить поведение на экране с отверстием камеры, полноэкранных видео, клавиатуре, поворотах и рядом с вырезом; отступы на других телефонах рассчитывать от WindowInsets

## P0. Погода и виджеты

- [ ] Внешний AppWidget — стабильный статический/кадровый RemoteViews, без обещаний настоящих 60 FPS.
- [ ] Погода по выбранному городу или приблизительной локации, ручное обновление и метка актуальности.

- [ ] Встроенные календарь, часы, батарея и медиапанель с разрешениями по запросу.

## Обязательная матрица тестов

1. Samsung Galaxy S24 Ultra, Android 16 / One UI: чистая установка, обновление, лаунчер, живые обои, виджет, переход Samsung Weather.
2. Android 8–10 ARMv7; Android 12–14 arm64; Android 15–16 arm64.
3. Проверка подписанного APK поверх предыдущего релиза, отказ от повреждённого APK, отсутствие регрессий.
4. Тесты на 60/120 Гц, минимальной яркости, в энергосбережении, после перезагрузки, поворотов экрана и нехватки сети.
5. Автоматические скриншоты всех погодных режимов; визуальное сравнение с концептами, ледяной ночи до/во время/после касания на эмуляторе, и реальный видеотест 30–60 секунд на Samsung.
6. Проверка доступности, контраста, локализации и краевых случаев при пустой погоде.

**Критерий выпуска:** все P0 закрыты, сборка `assembleRelease` подписана постоянным ключом, проходит smoke + реальную проверку на Samsung, а ссылка на GitHub Releases содержит только проверенный stable APK.
