# AURA GLASS — подключаемые виджеты и сервисы

## Принцип

Внутренние виджеты используют общий `GlassCard`/общее состояние темы: температура цвета, размытие, радиус, освещение, анимации. Внешние Android AppWidgets встраиваются с помощью стандартного `AppWidgetHost` без принудительной подмены их внешнего вида: приложения-поставщики управляют содержимым. Для общего оформления может использоваться только законная рамка/контейнер, не нарушающий взаимодействие.

## Этапы

**В релиз v1.0:**
- AURA Weather (Open-Meteo, город/локация, системный переход к Samsung Weather).
- Часы/будильник, календарь (CalendarContract с разрешением), батарея, быстрые заметки.
- Поддержка внешних Android AppWidgets через `AppWidgetHost`.
- Медиакарточка с безопасным поведением; расширенное управление медиа только с разрешением пользователя.
- Несколько размеров, длинное нажатие, выбор типа стекла и возможность скрыть виджет.
- Режим «Без подключений» — все сетевые интеграции можно выключить.

**В следующих версиях после тестирования:**
- Google Tasks/Calendar и Outlook через OAuth и минимальные запрошенные области доступа.
- Home Assistant: плитки сценариев/датчиков при явной авторизации.
- Health Connect: только при отдельном согласии, без загрузки чувствительных данных на сервер AURA.
- Погодные источники-плагины: явный выбор провайдера, лимиты API, кеш и offline fallback.
- Опциональные сторонние расширения с API/versioning и возможностью полного отключения.

## Идеи, которые берём из существующих решений

- Niagara Launcher: быстрый доступ к избранному, минимализм, всплывающие папки; не перегружать домашний экран.
- Smart Launcher: адаптивная сетка, гибкая компоновка и сортировка.
- Lawnchair/Launcher3: стандартный Android виджет-хост, поддержка пакетов иконок, Material You и резервные копии.
- Kustom/KWGT/KLWP: шаблоны и экономные обновления в зависимости от видимости, а не постоянные 60 FPS для каждого виджета.
- Собственное отличие AURA — *единая адаптивная атмосфера* дождя, льда, прозрачного стекла и времени суток.

## Безопасность

Разрешения отдельно для каждого провайдера; токены — только в защищённом локальном хранилище. Никаких логинов/паролей в коде, APK, общих логах или GitHub. Удаление интеграции стирает её локальные токены и кеш; полная работа лаунчера не зависит от подключения сервисов.
