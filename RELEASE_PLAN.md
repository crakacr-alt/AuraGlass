# AURA GLASS — критерии полноценного релиза

Статус: **готовится**, выпуск v1.0 запрещён до прохождения всех обязательных пунктов. Текущая альфа не является готовым приложением.

## P0. Установка, безопасность, обновление

- [ ] Единый приватный release-keystore хранится в GitHub Actions Secrets, не в репозитории; сертификат остаётся одним и тем же между версиями.
- [ ] Версии используют неизменный `applicationId = com.auraglass.app`, всегда увеличивающийся `versionCode`; `versionName` соответствует тегу релиза.
- [ ] CI проверяет APK Signature Scheme, package ID, минимальную версию Android, сертификат подписи и установку поверх предыдущего подписанного релиза.
- [ ] При первом переходе с debug-alpha пользователь получает предупреждение о возможной несовместимости подписи; настройки экспортируются до удаления.
- [ ] Стабильная версия публикуется **только вручную**, только после тестов и подписи; нет автоматических публикаций на каждый push.
- [ ] Проверка обновлений через официальный GitHub Releases API (только stable, не prerelease), с настройкой частоты и возможностью отключить. Скачивание и установку подтверждает пользователь.
- [ ] Проверка SHA-256 загружаемого APK и совпадения сертификата до передачи системному установщику; откат версии запрещён.
- [ ] Нет root, несанкционированного изменения системных параметров или автоматической смены обоев.

## P0. Полноценный лаунчер

- [ ] AURA появляется в выборе домашнего приложения на Samsung One UI и других поддерживаемых Android.
- [ ] Рабочий стол открывается и по нажатию Home, и после перезапуска смартфона.
- [ ] Редактируемые страницы; перетаскивание и удаление ярлыков; создание/редактирование папок.
- [ ] Dock, сетка, поиск, сортировка и скрытие приложений.
- [ ] Поддержка внешних виджетов Android через `AppWidgetHost`: выбор, привязка, настройка, изменение размера, обновление и удаление.
- [ ] Жесты и системная навигация не вызывают мерцаний, зависаний или блокировки пользователя.
- [ ] Настройки сохраняются; есть резервное копирование, восстановление и возврат к One UI Home.

## P0. Живые обои

- [ ] Реальный сервис WallpaperService с системным предпросмотром, выбором "Установить" / "Оставить системные".
- [ ] Анимация остаётся живой за иконками лаунчера; корректно останавливается на выключенном экране.
- [ ] Режимы: ясная погода, дождь, гроза, снег, лёд, роса, туман; день/вечер/ночь и переходы.
- [ ] Нет растяжений, видимых швов, мерцаний/скачков при изменении экрана или погодных условий.
- [ ] Энергосберегающий режим, снижение частоты кадров вне экрана, проверка тепловых ограничений.

## P0. Дизайн и анимации

- [ ] Цвета/контраст/размеры сверены с утверждёнными концептами для Galaxy S24 Ultra.
- [ ] Правдоподобные прозрачные панели с ограниченным, читаемым размытием и стеклянными бликами.
- [ ] Переходы: временной цикл, погодные режимы, нажатия на ярлыки, открытие папок, панели и редактор.
- [ ] Плавные 60 Гц на S24 Ultra в обычном режиме, адаптация под частоту экрана и Battery Saver.
- [ ] Учитываются Reduce Motion, AMOLED/тёмный режим, динамический цвет и контрастность.

## P0. Погода и виджеты

- [ ] Собственный погодный виджет с единой системой стекла/света и анимациями **внутри AURA Home**.
- [ ] Внешний AppWidget — стабильный статический/кадровый RemoteViews, без обещаний настоящих 60 FPS.
- [ ] Погода по выбранному городу или приблизительной локации, ручное обновление и метка актуальности.
- [ ] Нажатие на виджет открывает Samsung Weather, если это поддерживается установленной версией; иначе понятный fallback.
- [ ] Встроенные календарь, часы, батарея и медиапанель с разрешениями по запросу.

## P1. Открытые интеграции и лучшие практики

- [ ] «AURA Widget Bridge» — общий контракт данных, обновления, состояния, разрешений и настроек.
- [ ] Поддержка любых стандартных Android AppWidgets: календарь, заметки, задачи, музыка, мессенджеры.
- [ ] Опциональные адаптеры Google Calendar/Tasks, Microsoft Outlook, Home Assistant, Health Connect — только после согласия и официальной авторизации.
- [ ] Виджет-стек и контекстные предложения (пользователь может отключить).
- [ ] Импорт/экспорт пресетов и резервных копий; адаптивные иконки, пакеты иконок.

## P2. После v1.0

- [ ] Астрономический цикл: восход/закат, фаза луны, редкие метеоры и художественное северное сияние.
- [ ] Продвинутые эффекты: детализированный рефракционный дождь, микрокапли, кристаллизация, реалистичные облака и глубина.
- [ ] Качественные темы пресетов, расширенные доступные интеграции и платформа сторонних расширений.

## Обязательная матрица тестов

1. Samsung Galaxy S24 Ultra, Android 16 / One UI: чистая установка, обновление, лаунчер, живые обои, виджет, переход Samsung Weather.
2. Android 8–10 ARMv7; Android 12–14 arm64; Android 15–16 arm64.
3. Проверка подписанного APK поверх предыдущего релиза, отказ от повреждённого APK, отсутствие регрессий.
4. Тесты на 60/120 Гц, минимальной яркости, в энергосбережении, после перезагрузки, поворотов экрана и нехватки сети.
5. Автоматические скриншоты всех погодных режимов; визуальное сравнение с концептами.
6. Проверка доступности, контраста, локализации и краевых случаев при пустой погоде.

**Критерий выпуска:** все P0 закрыты, сборка `assembleRelease` подписана постоянным ключом, проходит smoke + реальную проверку на Samsung, а ссылка на GitHub Releases содержит только проверенный stable APK.
